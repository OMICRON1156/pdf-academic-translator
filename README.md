# 📖 PDF Academic Translator

把 PDF 的外文人文社会科学专著整本翻译成简体中文，页数不变、版式对应、跨页段落连贯，可按需输出 PDF 或 PDF+EPUB。

> 本项目由一名没有任何代码基础、智力堪比一根成年香蕉的 vibecoder 贡献，100%不含任何人类劳动，从头到尾只有“俺寻思能跑起来啊”。

## PAT 能做什么

你给它一本英文（或者其他任意语言，但是从右到左读的语言暂时不行，等待阿拉伯语大手子推荐几个能处理复杂排版的组件）的学术专著 PDF，它帮你整本翻译成简体中文，并按你的选择输出 PDF 或 PDF+EPUB。全程不需要手动选语言，一般来说大模型自己会认，认错了算它的。

## 如何安装使用 PAT

复制本仓库的网址 `https://github.com/OMICRON1156/pdf-academic-translator` ，扔给 Codex，说一句 `帮我安装这个 skill`。剩下的交给它——你不需要会装，开发者也不会装，但 Codex 会。（好像能够一己之力 vibecode 一个这个玩意儿出来，还是蛮装的）

安好之后再 Codex 对话框内添加需要翻译的 PDF 附件，选择对话框右下角的 Luna 模型，在对话框中输入 `调用 pdf-academic-translator 技能翻译这份 PDF 文件`

在配置好 DeepSeek 的 API Key 之后，Luna 将开始推进各个过程并进行基础性的审计。有任何不对劲的地方，请直接向 Luna 提问。

请参阅各个社交媒体的图文教程获取 DeepSeek API Key，靠这个来贩卖 FOMO 的大有人在。ADHD 患者可以参阅视频教程。

## PAT 解决了一个很多翻译工具都假装看不见的问题

很多 PDF 翻译工具喜欢把 PDF 按页切碎，再逐页丢给大模型。上半截翻译成一句话，下半截翻译成另一句话，最后拼起来考一考读者的前额叶。

但是——俺寻思可以这么做：

1. **提取**：把 PDF 的文本和版式信息提取出来。
2. **结构化整理**：分清正文、页眉页脚、脚注、图注和噪声，认出印刷页码，并标记出哪些段落跨了页。
3. **全书分析**：先通读全书，整理出各节中心意思和整本书的术语表，免得翻译到第 300 页时忘了第 3 页的专名。
4. **翻译**：跨页段落一律当作一个完整的逻辑段来翻译，用 `[PB]` 标签记下换页位置，绝对不拆成两半各译各的。这是本项目的灵魂，也是开发者为数不多会说“绝对不”的事情。还有“绝对不意气用事”。
5. **排版合成**：把译文按页放回去，输出页数与原文一致的中文 PDF，用户选择 PDF+EPUB 时同时生成 EPUB，再生成一份按页码和文本块定位问题的错误报告。

## But at what cost

天下没有免费的上下文。为了让跨页段落不断气、术语全书统一，上行和下行 token 都比逐页翻译翻了几倍。（如果有优化思路可以私戳开发者喵谢谢喵）

好在梁叔叔的恩情还不完✋😭✋调用 DeepSeek 翻完一本书通常也就相当于一杯加麻加辣的椰椰西瓜。好像 DeepSeek 就要涨价了，梁子你给我等着！

## 关于 OCR 和公式识别：本项目没有，别找了

这个 skill **没有 OCR 能力**。 开源 OCR 的准确率确实比不过商用软件。要是把开源 OCR 工具整个塞进来，仓库体积会暴涨，装起来也麻烦。

所以如果你的 PDF 是扫描版（没有文字层），请先用 Acrobat、ABBYY 这类专业工具做一次 OCR，导出带文字层的 PDF，再扔进 Codex 里。数字版 PDF 自带文字层，直接扔进去就行。

这个 skill 也**没有公式识别能力**。如果需要在 PDF 中保留公式，可以使用**沉浸式翻译**插件，这个好像能保留公式的。

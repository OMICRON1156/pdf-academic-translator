你是一名 PDF 书籍版面整理专家。我会给你一本学术专著若干页的半结构化渲染数据，这些数据来自 PyMuPDF 对 OCR 文本层的提取。每页包含若干文本块，每块有 block_id、bbox 坐标、若干行（每行有 line_id、bbox、text、sizes、fonts、labels）。

请完成以下工作：
1. 判断每个文本块的性质（kind），只允许使用以下值：
   - page_header_footer：页眉或页脚（通常位于页顶或页底，含书名、章名或页码）
   - heading：标题（章节标题、小节标题、无编号小标题等，不区分级别；字号通常大于正文，可能加粗或居中）
   - body：正文段落
   - footnote：脚注（位于页面底部，字号小于正文）
   - caption：题注或图注（图片说明、表题）
   - noise：噪声块（如纯空格、孤立标点、无意义碎片），应丢弃

2. 识别每页的印刷页码（page_number）：页码通常是页眉或页脚中的数字。从该页渲染数据中找出真正的印刷页码并填入 page_number 字段（整数）；如果该页没有页码，填 null。不要把脚注引用标记（如 32、33）误当成页码。

3. 判断页面是否空白（is_blank）：如果页面没有任何有效文本块且没有图像，is_blank 填 true，此时 blocks 可为空数组；否则填 false。

4. 对每个块的文本做轻度整理，输出清理后的原文文本：
   - 原文可能是英语、法语、德语、日语等任意语言，断词连字符规则按该语言的实际排版习惯执行；不使用连字符断词的语言忽略相关规则
   - 合并行尾断词连字符（如 crim- 与 inal 合并为 criminal）
   - 保留真正的复合词连字符（如 red-hot、oath-taking）
   - 去除零宽空格、行尾多余空格，规整连续空格
   - 修正明显的 OCR 错字
   - 除上述外不要改动内容：不得删减、重写、补充或改动任何句子，不得改动专名、数字、年份、脚注引用标记

5. 识别跨页段落，在 note 字段标注。判断标准是【正文段落是否延续】，与句子是否完整无关：即使页尾块以句号、问号或感叹号结尾，只要同一段落尚未结束、后续页面继续承接，仍然标注。跨页标签只用于真正的页边界：
   - note 取值：""（不跨页）、["continuation_from_prev"]（承接上一页）、["continues_to_next"]（续至后续页）、["continuation_from_prev","continues_to_next"]（组合标记，仅当该页只有一个正文块、它既是页首正文块又是页尾正文块时使用）。
   - continuation_from_prev：仅当该块是当前页【第一个正文块】（页眉之后）且确实是上一页段落的延续时标注；同一页最多一个。
   - continues_to_next：仅当该块是当前页【最后一个正文块】（脚注之前）且确实延续到后续页面时标注；同一页最多一个。
   - 跨页承接不必是相邻页：续页段落之后可以隔整页插图、空白页或只有图注/脚注的页面，再出现承接文本；中间的隔页不得包含正文段落。若中间页包含正文，则该正文块必须参与承接标注，不能跳过。
   - 每页最多一组跨页标记（组合标记算一组）。
   - 同一页内相邻块之间即使语义连续，也不要标跨页标签。
   - 索引、参考文献、目录等栏式文本中的 "(续)"、"cont."、"（续）" 行不是正文段落，一律不要标 continuation_from_prev；多栏小字号文本同样不参与跨页判断。
   - 脚注、图注等非正文块不参与跨页判断；正文块是否延续只看它自身段落是否结束，与它后面是否有脚注无关。
   - 以数字或字母编号开头的列表项（如 1.、2.、3.、a) 等）是独立条目，即使以分号结尾也是完整的列表项，一律不要标跨页标记；只有真正的叙述段落跨页才算跨页段落。

6. 每页的 blocks 数组按页面实际阅读顺序（页眉在前，正文按从上到下，页脚在后）排列。

输出要求（以下任何一条不满足，输出即不合格）：
- 只输出一个 JSON 对象，输出必须以 { 开始、以 } 结束：不要 Markdown 围栏、不要反引号、不要解释文字、不要注释、不要"好的，以下是结果"之类的引导语、不要在 JSON 前后附加任何字符。
- JSON 必须严格合法：键名和字符串一律用双引号；布尔值用 true/false；空值用 null；数组和对象的最后一项不要加逗号；不要使用单引号；不要省略字段，也不要新增字段。
- 结构必须与下列示例完全一致，字段名不能拼错或改名：
{"pages":[{"page_no":1,"page_number":55,"is_blank":false,"blocks":[{"block_id":"p1-b0","kind":"page_header_footer","text":"清理后的文本","note":""}]}]}
- note 取值为空字符串 ""，或标记数组：["continuation_from_prev"]、["continues_to_next"]、["continuation_from_prev","continues_to_next"]（组合仅限该页只有一个正文块时使用）。
- page_no 与输入一致；page_number 是该页印刷页码（整数或 null）；is_blank 是布尔值。
- block_id 必须与输入完全一致，不得新增、删除或改名任何块；noise 块也保留 block_id。
- text 必须是原文清理后文本，保持每块为一个自然段落（块内多行合并成一个 text）。
- 输出前逐项自查：每个 block_id 都在输入中出现且只出现一次；kind 只使用六种允许值之一；note 只使用 ""、continues_to_next、continuation_from_prev 三种取值之一；每页 blocks 按阅读顺序排列。
